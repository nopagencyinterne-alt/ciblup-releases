# Ciblup pour Mac — versions publiées

Ce dépôt ne contient aucun code. Il sert uniquement à distribuer les versions de l'application Ciblup pour Mac.

- `stable.json` et `beta.json` : la fiche signée de la dernière version de chaque canal.
- Les « Releases » : l'application de chaque version.

L'application vérifie la signature de chaque fiche avant de proposer une mise à jour.
